# Fotos de perfil de los jugadores

Pon aquí la foto de cada jugador con **su ID como nombre de archivo**:

- `p12.jpg` (o `p12.png`) → foto de Luis Fernando Lugo
- Se usa sola en todo el sitio (Roster, perfil, Resumen, Comparar...). Si un
  jugador no tiene foto, se muestran sus iniciales como siempre.
- Recomendado: **cuadrada**, cara centrada, unos **400×400 px**, JPG de
  menos de 150 KB.
- Si cambias la foto de alguien por otra con el mismo nombre, sube la
  versión de caché en `sw.js` (`CACHE_VERSION`) para que se vea la nueva
  en los celulares que ya tenían la vieja guardada.
